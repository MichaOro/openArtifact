## 5.3 Backend components

Package `apps/backend/openartifact/`.

| Component | Location | Responsibility |
|-----------|----------|----------------|
| `app` | `app.py` | FastAPI factory, lifespan, exception handlers, owns the `EventBus` |
| `api.routes` | `api/routes.py` | `/api/health`, `/api/info` |
| `api.tasks` | `api/tasks.py` | Artifact CRUD, lane/position/parent changes; publishes events after commit |
| `api.events` | `api/events.py` | `GET /api/events` (SSE stream) |
| `events` | `events.py` | In-process publish/subscribe `EventBus`, SSE framing |
| `tasks` | `tasks/` | `schemas` (Pydantic), `repository` (persistence, ordering, parent rules, numbering), `lanes` (lane definition and colours) |
| `api.workflows` | `api/workflows.py` | Workflow, node and edge endpoints; every change is saved at once |
| `workflow` | `workflow/` | `node_types` (the kinds of nodes as classes, their registry), `rules` (checks an edge against them), `schemas`, `repository` |
| `api.runs` | `api/runs.py` | Start, stop and list pipeline runs |
| `engine` | `engine/` | `chain` (order of a pipeline), `snapshot`, `runner` (`RunEngine`: starts, stops, executes runs, publishes `run.updated`) |
| `models` | `models/__init__.py` | SQLAlchemy models |
| `repositories` | `repositories/` | Project / WorkItem repositories (not yet used by the UI) |
| `web` | `web/` | Pages, `navigation` (navigation entries as classes, ADR-014), `RevalidatingStaticFiles` (`no-cache`) |
| `database`, `config`, `logging_config`, `exceptions`, `cli` | | Engine/session (WAL), settings, logging with secret masking, error types, entry point |
| `alembic/` | `alembic/versions/0001–0018` | Schema migrations |
