## 5.3 Backend components

Package `apps/backend/openartifact/`. Every Python module is listed; the list was built from the source tree. Dependencies
point downwards: `api` and `web` use `tasks`, `engine`, `graph`, `agents` and `secret_*`; `engine` uses `graph`, `models`, `agents`, `secret_*`;
`engine`, `graph`, `tasks` and `secret_*` import neither `api` nor `web`.

### Application, security and infrastructure

| Module | Responsibility |
|--------|----------------|
| `app.py` | Application factory `create_app` (`openartifact.app:create_app`), middlewares, lifespan (database check, run recovery, MCP lifespan, shutdown), exception handlers; owns the `EventBus`, `SecretStore`, `RunEngine` and `ArtifactService` (on `app.state`) |
| `cli.py` | The `openartifact` entry point: reads the settings and starts `uvicorn` |
| `config.py` | `Settings` (`OPENARTIFACT_*`, validated), `get_settings`, `security_problems` (the application refuses to start with a token but without a secret key of its own) |
| `version.py` | The one version string (release tags equal it) |
| `security.py` | `AccessGate` (whole application), `TokenProtected` (the MCP mount), `token_matches`, session cookie (sign, verify, expire), `require_api_token` (ADR-016, ADR-017) |
| `api/hardening.py` | Request hardening middlewares: `SecurityHeaders` (CSP and others), `HostCheck`, `BodyLimit`, `CrossSiteGuard` (ADR-017) |
| `events.py` | In-process publish/subscribe `EventBus` (bounded subscribers), SSE framing |
| `database.py` | One engine and one session maker per process: `create_engine_for` (shared with Alembic), `build_engine`, `new_session`, `get_db_session` (a request session that is not committed automatically: whoever changes data commits); WAL and foreign keys per connection |
| `logging_config.py` | One log format; the token and the secret key are masked, `masked_in_logs` masks the values of secrets a node uses while it runs |
| `exceptions.py` | `OpenArtifactError`, `ArtifactError` (a refusal with an HTTP status), `ConfigurationError` |
| `schemas_common.py` | Shared schema types: `UtcDateTime` (ISO-8601 with `Z`) |
| `models/__init__.py` | SQLAlchemy models: `Task`, `Lane`, `TaskNumberSeq`, `Graph`, `GraphNode`, `GraphEdge`, `PipelineRun`, `RunStage`, `Execution`, `RunNodeResult`, `Secret`, `ArtifactType`, `ArtifactTypeField`, `LlmProvider`, `LlmModel`, `Agent`, `AgentVersion`; enums `CreatedBy`, `StartedBy`, `RunStatus`, `StageStatus`, `GraphKind`, `NodeKind` |
| `alembic/` (next to the package) | Schema migrations `0001` to `0033` (one head; `tests/test_migrations.py` checks that models and migrations agree) |

### Artifacts (board)

| Module | Responsibility |
|--------|----------------|
| `tasks/service.py` | `ArtifactService`: everything that can be done with artifacts; validates, locks while processing, publishes events after commit, records `created_by`, starts and stops runs, answers the history questions (executions, flow, step, retention policy) |
| `tasks/repository.py` | Persistence of artifacts: ordering, parent rules, numbering |
| `tasks/schemas.py` | Request and response models for artifacts and for starting a run |
| `tasks/lanes.py` | The lanes (rows of `lanes`): the effective list with counts and colours, adding, renaming and deleting with their rules (limit, unique titles, only empty lanes), the key of a title and the check of a lane key |
| `artifact_types/fields.py` | Pure rules for parameters (ADR-035): `FieldSpec`, the check of a definition, of a value and of all parameters of an artifact (`validate_parameters`), the `card` a run gets (`card_values`), and which changes of a type could invalidate stored values (`breaking_changes`) |
| `artifact_types/service.py` | `ArtifactTypeService` (list, create, replace, delete types; publishes `artifact_types.changed`) and what `ArtifactService` and the engine call: `assign_new`, `assign_update` (type and parameters of an artifact, 422 with one line per problem) and `card_of` |
| `artifact_types/schemas.py` | Request and response models of the types API |

### Graph (pipelines and action definitions)

| Module | Responsibility |
|--------|----------------|
| `graph/node_types.py` | Kinds of nodes as classes with ports, settings and bounds (`trigger`, `stage`, `action`, `pipeline`, `complete`, `timer`, `output`, `code`, `http`, `if`, `switch`, `agent`); the registry behind `GET /api/node-types`; validation of settings |
| `graph/rules.py` | Checks an edge against the ports of its nodes |
| `graph/schemas.py` | Request and response models of the editor API |
| `graph/repository.py` | Persistence of graphs, nodes and edges; every change is saved at once |
| `graph/slug.py` | Readable URL names |

### Engine (running and recording)

| Module | Responsibility |
|--------|----------------|
| `engine/runner.py` | `RunEngine`: atomic start (claims the run, opens the execution), run cap, stop, the walk over stages and actions, recovery after a restart, shutdown, `run.updated`; records every step and bounds the stored output |
| `engine/chain.py` | Pure functions: the order of a pipeline and the edge to follow |
| `engine/snapshot.py` | The frozen copy of a pipeline and the definitions it uses |
| `engine/targets.py` | Resolves the pipeline, stage and action a start begins at |
| `engine/schemas.py` | Read models: run, stage, step, execution, list and policy |
| `engine/executors.py` | Executor registry: one async function per node kind `(node, limits, view) -> NodeResult` (Code, HTTP, timer, If, Switch, Agent); resolves and masks secrets around it (also the agent's provider key and its `detail`); `Limits` |
| `engine/results.py` | `NodeResult`: outcome, exit code, text, reason, data, duration, variables, port, and `detail` (kept with the step only, never in the run context) |
| `engine/code_runner.py` | Runs a Code node as a child process (private directory, clean environment, own process group, resource limits through a wrapper, `PR_SET_PDEATHSIG`) |
| `engine/code_registry.py` | Notes started Code processes on disk; `cleanup_leftovers` ends orphans at the next start (Linux, `/proc`) |
| `engine/http_runner.py` | Runs an HTTP node: one request, no redirects, resolved address checked and used directly, size and time bounds; `guarded_exchange` is the same path for the LLM providers |
| `engine/history.py` | `ExecutionHistory`: open and close an execution, retention (`prune`), delete, events after commit |
| `engine/history_query.py` | The global list: filters, keyset cursor, summary |
| `engine/flow.py` | Replays the walked path over the frozen snapshot: visits, traversed edges, reached nodes; fills in old snapshots |
| `engine/flow_schemas.py` | Read models of the flow: `ExecutionFlow`, `FlowVisit`, `FlowGraph`, `FlowNode`, `FlowEdge`, `TraversedEdge`, `FlowReached` |

### Agents (ADR-037)

| Module | Responsibility |
|--------|----------------|
| `agents/schemas.py` | `AgentConfig` (the content of a draft and a version) with the bounds of every setting, `OVERRIDABLE`; request and response models of the agents and providers API |
| `agents/resolve.py` | Pure: a published configuration plus a node's overrides; provider and model in effect; `freeze` (what a snapshot keeps per agent node) |
| `agents/render.py` | Pure: `${input.NAME}` placeholders, the rules for prompts, the node's input mapping (`name = value`), resolving inputs against the run context, filling the prompts |
| `agents/freeze.py` | Reads agents, versions, providers and models for a snapshot (`freeze_agents`, called by `engine/snapshot.py`) |
| `agents/client.py` | OpenAI-compatible endpoint through `guarded_exchange`: model list, OpenRouter key check, one chat completion; `ProviderError` with `transient` |
| `agents/runtime.py` | One request with retries (3, 10, 30, 60 s; `Retry-After`) within the node's time limit; `run_node` builds the `NodeResult` and its `detail`; writes nothing |
| `agents/service.py` | `AgentService`: CRUD, draft, publish, republish (rollback), uses, preview; `node_hints` for the editor; publishes `agents.changed` |
| `agents/providers.py` | `ProviderService`: CRUD, connection test, model list and models by hand, references that block deleting; publishes `providers.changed` |

### Credentials

| Module | Responsibility |
|--------|----------------|
| `secret_crypto.py` | AES-256-GCM with a key derived by HKDF-SHA256 from `OPENARTIFACT_SECRET_KEY`; the name is the associated data |
| `secret_store.py` | `SecretStore`: `put`, `resolve` (executors only), names, uses; writable only with a token and a secret key of the operator's own |
| `secret_refs.py` | The syntax `${secret:NAME}`: find, substitute, mask by value (as is, percent-encoded, Base64, JSON-escaped) |

### Interfaces

| Module | Responsibility |
|--------|----------------|
| `api/routes.py` | `GET /health` (open, under any host), `GET /api/info` |
| `api/deps.py` | Dependencies: `SessionDep`, `ServiceDep`, `TypesDep`, `AgentsDep`, `ProvidersDep`, `EngineDep`, `EventBusDep` |
| `api/lanes.py` | Browser API for the lanes: list, add, rename, delete (`/api/lanes`); `/api/v1/lanes` mirrors it |
| `api/artifact_types.py` | Browser API for artifact types (`/api/artifact-types`); `/api/v1/artifact-types` mirrors it |
| `api/tasks.py` | Browser API for artifacts: CRUD, lane/position/parent changes; run start and stop; executions, flow, step and history policy of an artifact |
| `api/runs.py` | `GET /api/runs`, `GET /api/runs/{task_id}/results` |
| `api/executions.py` | The global execution list `GET /api/executions` |
| `api/graphs.py` | Router factory `build_graph_router(kind)`: `pipelines_router` (`/api/pipelines`, with `/stages`) and `actions_router` (`/api/actions`) with the same node and edge endpoints; a graph under the wrong kind answers 404; `/api/node-types` |
| `api/agents.py` | Router builders for `/api/agents` and `/api/providers`, mounted twice: for the browser and under `/api/v1` (ADR-037) |
| `api/secrets.py` | `/api/secrets`: names and dates, never values |
| `api/v1.py` | Integration API `/api/v1` (artifacts, runs, executions, secrets, pipelines) |
| `mcp_server.py` | MCP server `/mcp` with 19 tools (agents and providers read-only); both it and `/api/v1` need the API token and go through `ArtifactService` |
| `api/events.py` | `GET /api/events` (SSE stream, capped by `max_sse_subscribers`) |
| `web/routes.py` | HTML pages (`/`, `/pipelines`, `/actions`, `/executions`, the flow page `/artifacts/{ref}/executions/{id}`, `/artifact-types`, `/agents`, `/agents/{id}`, `/settings/providers`), `/login`, `/logout` |
| `web/navigation.py` | Navigation entries as classes (ADR-014) |
| `web/static.py` | `RevalidatingStaticFiles` (`no-cache`) |

`templates/` and `static/` are plain folders, not Python packages ([5.4](05.04-frontend-components.md));
`openartifact/__init__.py` does not import the application. The persistence convention is one `repository` module per
aggregate next to its service (`tasks/repository.py`, `graph/repository.py`); the older `repositories/` package is gone
([ADR-032](../../adr/032-removal-of-the-unused-workspace-model.md)). Engine internals: [5.6](05.06-execution-engine-internals.md).
