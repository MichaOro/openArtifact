## 5.3 Backend components

Package `apps/backend/openartifact/`.

| Component | Location | Responsibility |
|-----------|----------|----------------|
| `app` | `app.py` | Application factory `create_app` (`openartifact.app:create_app`), middlewares, lifespan (database check, run recovery, MCP lifespan, shutdown), exception handlers; owns the `EventBus`, `RunEngine` and `ArtifactService` |
| `security` | `security.py` | Access protection: `AccessGate` (whole application), `TokenProtected` (the MCP mount), `token_matches`, `token_error`, session cookie (sign, verify, expire), `require_api_token` (ADR-016, ADR-017) |
| `api.hardening` | `api/hardening.py` | Request hardening middlewares: `SecurityHeaders`, `HostCheck`, `BodyLimit`, `CrossSiteGuard` (ADR-017) |
| `api.routes` | `api/routes.py` | `GET /health` (open, under any host), `GET /api/info` |
| `api.deps` | `api/deps.py` | Dependencies: `SessionDep`, `ServiceDep`, `EngineDep`, `EventBusDep` |
| `api.tasks` | `api/tasks.py` | Browser API for artifacts: CRUD, lane/position/parent changes |
| `api.events` | `api/events.py` | `GET /api/events` (SSE stream, capped by `max_sse_subscribers`) |
| `events` | `events.py` | In-process publish/subscribe `EventBus`, SSE framing |
| `tasks` | `tasks/` | `service` (`ArtifactService`: everything that can be done with artifacts; validates, locks while processing, publishes events after commit, records `created_by`), `schemas`, `repository` (persistence, ordering, parent rules, numbering), `lanes` (lane definition and colours) |
| `api.graphs` | `api/graphs.py` | Router factory `build_graph_router(kind)`: `pipelines_router` (`/api/pipelines`, with `/stages`) and `actions_router` (`/api/actions`) with the same node and edge endpoints; every change is saved at once; a graph under the wrong kind answers 404; `/api/node-types` |
| `graph` | `graph/` | `node_types` (kinds of nodes as classes, registry, settings, timer bounds), `rules` (checks an edge against them), `schemas`, `repository`, `slug` |
| `api.v1`, `mcp_server` | `api/v1.py`, `mcp_server.py` | Integration API `/api/v1` and MCP server `/mcp` (eight tools) for scripts and agents; both need the API token, both go through `ArtifactService` |
| `api.runs` | `api/runs.py` | Start, stop and list pipeline runs for the browser |
| `engine` | `engine/` | `chain` (order of a pipeline), `snapshot`, `targets` (resolves pipeline/stage/action), `schemas` (`RunRead`, `RunStageRead`), `runner` (`RunEngine`: atomic start, run cap, stop, execution, recovery, `run.updated`) |
| `models` | `models/__init__.py` | SQLAlchemy models (`Task`, `TaskNumberSeq`, `Graph`, `GraphNode`, `GraphEdge`, `PipelineRun`, `RunStage`; `Project` and `WorkItem` are unused and quarantined) |
| `repositories` | `repositories/` | Project / WorkItem repositories: unused, quarantined; `tasks/repository.py` and `graph/repository.py` are the live convention |
| `web` | `web/` | Package: pages and `/login`, `/logout` (`routes`), `navigation` (navigation entries as classes, ADR-014), `RevalidatingStaticFiles` (`static`, `no-cache`) |
| `database` | `database.py` | One engine and one session maker per process: `build_engine`, `create_engine_for` (shared with Alembic), `new_session`, `get_db_session` (a request session that is not committed automatically: whoever changes data commits); WAL and foreign keys per connection |
| `config`, `version`, `exceptions`, `schemas_common`, `logging_config`, `cli` | | Settings (`OPENARTIFACT_*`); the one version string; `ArtifactError` and the other error types; shared schema types (UTC timestamp); logging with secret masking; the `openartifact` entry point |
| `alembic/` | `alembic/versions/0001` to head | Schema migrations (20 at the time of writing) |

`templates/` and `static/` are plain folders, not Python packages; `openartifact/__init__.py` does not import the
application.
