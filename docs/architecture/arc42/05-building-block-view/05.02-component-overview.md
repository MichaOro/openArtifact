## 5.2 Component Overview

Three entry points share one service and one run engine, inside a single `uvicorn` process:

```
Browser                          ┌────────────────────────────────────────────────────┐
 pages, /api/*, SSE ───────────► │ middlewares: SecurityHeaders → HostCheck → BodyLimit │
Scripts ── /api/v1 (Bearer) ───► │              → CrossSiteGuard → AccessGate         │
LLM agents ── /mcp (Bearer) ───► ├────────────────────────────────────────────────────┤
                                 │ api/tasks · api/runs · api/graphs · api/v1 · /mcp   │
                                 │ web/routes (HTML, /login, /static) · api/events      │
                                 │            │                                        │
                                 │            ▼                                        │
                                 │  tasks/service.ArtifactService ──► events.EventBus ─┼─► SSE
                                 │      │                │                              │
                                 │      ▼                ▼                              │
                                 │ tasks/repository  engine/RunEngine (asyncio tasks)   │
                                 │ graph/repository       │                             │
                                 │      └────────┬────────┘                             │
                                 │  database.new_session (async SQLAlchemy) ──► SQLite  │
                                 └────────────────────────────────────────────────────┘
Container start: docker-entrypoint.sh → alembic upgrade head → exec openartifact (cli.main → uvicorn)
```

The browser API (`/api/tasks`, `/api/runs`), the integration API and the MCP tools are thin layers over
`ArtifactService`, which validates, applies the lock while an artifact is processed, publishes events and records
`created_by`. The pipeline editor's API (`/api/pipelines`, `/api/actions`) goes to `graph/repository`. The
`RunEngine` runs one `asyncio` task per active run, saves each step and publishes `run.updated`.
