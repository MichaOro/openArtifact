## 5.5 Interfaces

With an API token configured, every interface except `/health`, the sign-in page and static files needs it
(ADR-016); the guide [Sign in and use the API and MCP](../../../guides/integration.md) has examples.

| Interface | Protocol | Notes |
|-----------|----------|-------|
| `GET/POST /api/tasks`, `GET/PATCH/DELETE /api/tasks/{id}` | HTTP + JSON | The browser's API. PATCH is partial: title, body, status, `before_id`, `parent_id`; `number` is read-only |
| `/api/pipelines`, `/api/pipelines/{id}`, `.../nodes`, `.../edges`, `GET .../stages` | HTTP + JSON | CRUD for pipeline definitions (a graph of kind `pipeline`); the detail answers `{graph, nodes, edges}`; connections are validated (422) |
| `/api/actions`, `/api/actions/{id}`, `.../nodes`, `.../edges` | HTTP + JSON | The same for action definitions (kind `action`, no `/stages`); a graph under the wrong kind answers 404 |
| `GET /api/node-types` | HTTP + JSON | The kinds of execution nodes with their scopes (`pipeline`, `action`), ports and settings |
| `GET /api/runs`, `POST /api/tasks/{id}/run`, `POST /api/tasks/{id}/run/stop` | HTTP + JSON | Start body `{pipeline_id?, stage_id?, action_id?}`; answers a typed `RunRead` (`pipeline_id` where it is now, `root_pipeline_id` where it started; `updated_at` ISO-8601 UTC with `Z`); `409` while running or starting, `429` at the run cap |
| `/api/v1/*` | HTTP + JSON | Integration API: `GET /pipelines`, `GET/POST /artifacts`, `GET/PATCH/DELETE /artifacts/{ref}`, `GET/POST /artifacts/{ref}/run`, `POST /artifacts/{ref}/run/stop`; `ref` is the number or the id; bearer token; `401` without it or while none is configured |
| `/mcp` | MCP (Streamable HTTP, stateless) | Eight tools (`list_pipelines`, `list_artifacts`, `get_artifact`, `create_artifact`, `update_artifact`, `start_processing`, `stop_processing`, `get_processing_status`); bearer token only |
| `GET /api/events` | SSE | `task.created`, `task.updated`, `task.moved`, `task.deleted`, `board.resync`, `run.updated`; `503` at the stream cap |
| `GET /health` | HTTP | Docker health check: open without a token and under any `Host` header; answers status and version. `/api/health` does not exist |
| `GET /api/info`, `/api/docs`, `/openapi.json` | HTTP | Application information and OpenAPI (Swagger UI offers an *Authorize* button for the token); need the token |
| `GET /`, `/pipelines`, `/actions`, `/static/*`, `/login`, `/logout` | HTML, assets | Server-rendered pages; assets revalidated on every load; `/login` and `/logout` are open |
| Request rules | HTTP | Unsafe methods are refused (`403`) when `Sec-Fetch-Site` is cross-site or same-site, or when `Origin` differs from `Host`; unsafe `/api` requests with a body need `Content-Type: application/json` (`415`); bodies over 1 MiB get `413` (4096 bytes for `/login`); `Host` outside `ALLOWED_HOSTS` gets `400` (ADR-017) |
| SQLite (WAL) | file | `/data/openartifact.db` |
| AI model providers, Git, webhooks, PostgreSQL as a data source | — | Planned through a connector layer; not built |
