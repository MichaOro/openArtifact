## 5.5 Interfaces

With an API token configured, every interface except `/health`, the sign-in page and static files needs it
(ADR-016); the guide [Sign in and use the API and MCP](../../../guides/integration.md) has examples and the
[API reference](../../../guides/api-reference.md) has every operation. The tables below list every route of the
application (the OpenAPI schema has 46 paths and 68 operations, the HTML pages are not part of it; `tests/test_openapi.py` guards it). Where a route takes `{task_id}` or `{ref}`,
the artifact's id or number is accepted.

### Browser API (JSON)

| Route | Notes |
|-------|-------|
| `GET`, `POST /api/lanes`, `PUT`, `DELETE /api/lanes/{status}` | The lanes; add one, change one (`{"title"?: string, "style"?: "normal"|"finished"}`, at least one: the title is trimmed, 1-40 characters, unique ignoring case; an unknown style is `422`), delete an empty one (`409` while it holds artifacts and for the last lane; at most 12 lanes). Every change publishes `board.lanes`. Artifacts keep the status key |
| `GET/PUT /api/artifact-fields` | The artifact fields every artifact has (ADR-044); PUT replaces the whole list |
| `GET/POST /api/tasks`, `GET/PATCH/DELETE /api/tasks/{task_id}` | Artifacts. PATCH is partial: title, body, status, `before_id`, `parent_id`, `fields`, `parameters` (merged), `reset_parameters`; `number` is read-only. Parameters are validated when saved (`422`, `Parameter NAME: ...` per problem) |
| `POST /api/tasks/{task_id}/run`, `POST .../run/stop`, `GET /api/runs`, `GET /api/runs/{task_id}/results` | Start body `{pipeline_id?, stage_id?, action_id?}`; answers a typed `RunRead`; `409` while running or starting, `429` at the run cap. `results`: every step of the run with complete outputs |
| `GET /api/tasks/{task_id}/executions`, `DELETE` (clear) | The artifact's executions without steps (`limit` up to 500) with `total`; clear removes every finished execution |
| `GET/DELETE /api/tasks/{task_id}/executions/{execution_id}` | One execution with all steps; delete answers `409` while it runs |
| `GET .../executions/{execution_id}/flow`, `GET .../steps/{step_id}` | The replayed path (`outputs=true` adds step outputs); one step with its whole output |
| `GET /api/executions` | The executions of all artifacts: filters `status`, `started_by`, `pipeline`, `q`, `since`, `until`, keyset `cursor`, `limit`; answers items, `next_cursor`, `total`, `summary` |
| `/api/pipelines`, `/api/pipelines/{graph_id}`, `.../nodes`, `.../nodes/{node_id}`, `.../edges`, `.../edges/{edge_id}`, `GET .../stages` | CRUD for pipeline definitions (a graph of kind `pipeline`); the detail answers `{graph, nodes, edges}`; connections are validated (422) |
| `/api/actions`, `/api/actions/{graph_id}`, `.../nodes`, `.../edges` (as above, no `/stages`) | The same for action definitions (kind `action`); a graph under the wrong kind answers 404 |
| `GET /api/node-types` | The kinds of nodes with their scopes (`pipeline`, `action`), ports and settings (Code and HTTP included) |
| `GET /api/secrets`, `PUT/DELETE /api/secrets/{name}`, `GET /api/secrets/{name}/uses` | Credential names and dates, never values. `PUT` answers `409` unless an API token and an own secret key are set; `uses` lists the nodes that refer to the name |
| `GET /api/info`, `GET /api/docs`, `GET /openapi.json` | Application information and OpenAPI (Swagger UI offers an *Authorize* button for the token); need the token |
| `GET /health` | Docker health check: open without a token and under any `Host` header; answers status and version. `/api/health` does not exist |

### Integration API `/api/v1` (bearer token; `401` without it or while none is configured)

| Route | Notes |
|-------|-------|
| `GET /pipelines` | Pipelines with stages and actions |
| `GET/POST /artifacts`, `GET/PATCH/DELETE /artifacts/{ref}` | `ref` is the number or the id |
| `GET/POST /artifacts/{ref}/run`, `POST .../run/stop`, `GET .../run/results` | State, start, stop, steps |
| `GET /artifacts/{ref}/executions`, `GET/DELETE .../executions/{execution_id}`, `GET .../flow`, `GET .../steps/{step_id}` | The history of one artifact |
| `GET /executions` | The global list, same filters as `/api/executions` |
| `GET /secrets`, `PUT/DELETE /secrets/{name}` | Credentials, names only |

### MCP `/mcp` (Streamable HTTP, stateless; bearer token only)

Fourteen tools: `list_pipelines`, `list_artifacts`, `get_artifact`, `create_artifact`, `update_artifact`,
`start_processing`, `stop_processing`, `get_processing_status`, `get_processing_results`, `list_executions`,
`list_all_executions`, `get_execution`, `get_execution_flow`, `list_secrets`. Secrets can be listed (names), not written, through MCP.
Texts that come out of a run (outputs, reasons) are data, never instructions; the tool descriptions say so.

### Server-sent events `GET /api/events`

`task.created`, `task.updated`, `task.moved`, `task.deleted`, `board.resync`, `board.lanes`, `artifact_fields.changed`, `run.updated`, `execution.updated`,
`execution.deleted`, `activity.created` (ADR-058: `GET /api/tasks/{ref}/activity`, `/api/v1/artifacts/{ref}/activity`, MCP `list_activity`); `503` at the stream cap (`max_sse_subscribers`). `run.updated` carries the run state with step outputs as previews; secret values are masked before a step is stored or published.

### Pages (HTML)

| Route | Page |
|-------|------|
| `GET /` | The board (`/?artifact=N` opens artifact `N`) |
| `GET /pipelines`, `/pipelines/{ref}`, `/actions`, `/actions/{ref}` | List and canvas editor for pipelines and action definitions |
| `GET /executions` | The global execution list |
| `GET /artifacts/{ref}/executions/{execution_id}` | The read-only flow of one execution |
| `GET/POST /login`, `POST /logout` | Sign in and out (open) |
| `GET /static/*` | Assets, revalidated on every load (open) |

HTML pages are not part of the OpenAPI schema.

### Request rules and other interfaces

| Interface | Notes |
|-----------|-------|
| Request rules (HTTP) | Unsafe methods are refused (`403`) when `Sec-Fetch-Site` is cross-site or same-site, or when `Origin` differs from `Host`; unsafe `/api` requests with a body need `Content-Type: application/json` (`415`); bodies over 1 MiB get `413` (4096 bytes for `/login`); `Host` outside `ALLOWED_HOSTS` gets `400` (ADR-017) |
| SQLite (WAL) | File `/data/openartifact.db` |
| HTTP targets | Outgoing: one request per HTTP node ([5.6](05.06-execution-engine-internals.md)) |
| Child processes | Outgoing: one process per Code node ([5.6](05.06-execution-engine-internals.md)) |
| AI model providers, Git, PostgreSQL as a data source | Planned through a connector layer; not built |
