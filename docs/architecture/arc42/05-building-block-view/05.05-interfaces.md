## 5.5 Interfaces

| Interface | Protocol | Notes |
|-----------|----------|-------|
| `GET/POST /api/tasks`, `PATCH/DELETE /api/tasks/{id}` | HTTP + JSON | PATCH is partial: title, body, status, `before_id`, `parent_id`; `number` is read-only |
| `/api/pipelines`, `/api/pipelines/{id}`, `.../nodes`, `.../edges`, `GET .../stages` | HTTP + JSON | CRUD for pipeline definitions (a graph of kind `pipeline`); the detail answers `{graph, nodes, edges}`; connections are validated (422) |
| `/api/actions`, `/api/actions/{id}`, `.../nodes`, `.../edges` | HTTP + JSON | The same for action definitions (kind `action`, no `/stages`); a graph under the wrong kind answers 404 |
| `GET /api/node-types` | HTTP + JSON | The kinds of execution nodes with their scopes (`pipeline`, `action`), ports and settings |
| `GET /api/runs`, `POST /api/tasks/{id}/run`, `POST /api/tasks/{id}/run/stop` | HTTP + JSON | Start body `{pipeline_id?, stage_id?, action_id?}`; a run reports `pipeline_id` (where it is now) and `root_pipeline_id` (where it started) |
| `/api/v1/*` | HTTP + JSON | Integration API for artifacts, pipelines and runs; needs the API token (`Authorization: Bearer`), 401 without it or while none is configured |
| `/mcp` | MCP (Streamable HTTP) | MCP server for agents with the same operations; needs the same token |
| `GET /api/events` | SSE | `task.created/updated/moved/deleted`, `board.resync` |
| `GET /api/health`, `/api/info`, `/api/docs` | HTTP | Health check for Docker (open), OpenAPI (Swagger UI offers an *Authorize* button for the token). With a token configured everything except `/health`, the sign-in page and static files needs it (ADR-016) |
| `GET /`, `/static/*` | HTML, assets | Server-rendered shell; assets revalidated on every load |
| SQLite (WAL) | file | `/data/openartifact.db` |
| AI agent execution, pipeline progress | — | Planned (WP-07/08) |
