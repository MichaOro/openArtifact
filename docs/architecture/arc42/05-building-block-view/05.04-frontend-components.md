## 5.4 Frontend components

Assets in `static/`, templates in `templates/`.

| Component | Location | Responsibility |
|-----------|----------|----------------|
| Design tokens | `css/tokens.css` | The only place with raw colours; light "Sand Dune", dark "Midnight Purple" |
| Styles | `css/base,components,forms,modal.css` | Reset, shell/board/cards, form controls, dialog and rail |
| Shell | `js/theme.js`, `js/main.js` | Theme and sidebar state, narrow-screen behaviour |
| Board | `js/tasks/board.js` | Single client state; idempotent `upsert`/`remove`; renders cards and relations |
| Live sync | `js/tasks/events.js` | `EventSource`, resync on (re)connect |
| Drag & drop | `js/tasks/dnd.js` | Pointer-Events controller; reports a placement, knows no API |
| Dialogs | `js/tasks/create-task-form.js`, `references.js`, `delete-task-dialog.js` | Dialog in create / view / edit mode, `#n` rendering as links, delete confirmation |
| Wiring | `js/tasks/main.js`, `js/tasks/api.js` | Actions with optimistic update and rollback; REST client |
| Editor | `js/editor/` (`list`, `editor`, `canvas`, `geometry`, `api`) | Pipeline / action list; editor with canvas (pan, zoom, move, connect) and inspector |
| Node kinds | `js/editor/node-types.js`, `inspector.js` | `NodeView` and one view per kind (looks, ports, rule mirror, inspector blocks); the shared inspector blocks with the New · Edit · Delete row (ADR-014) |
| Reusable | `js/components/` | `Modal`, `ConfirmDialog`, `CollapsibleNav`, `LanePicker` (lanes, parents), `ReferencePicker` (`#` in the body) |
| Templates | `templates/` | `base`, `index`, `components/*` (macros for sidebar, header, lane, modal, icons); `components/nav.html` renders every navigation from `web/navigation.py` |
