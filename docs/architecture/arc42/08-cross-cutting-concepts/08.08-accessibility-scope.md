## 8.8 Accessibility Scope

Decision: [ADR-030](../../adr/030-accessibility-scope.md). The owner decision: accessibility, in particular keyboard-only
connections in the graph editor and screen reader support, is a **later goal**; this chapter records what holds today so
that the limit is stated once and not by scattered side notes.

**What works today**

| Area | Support |
|------|---------|
| Board | Every pointer action has a keyboard alternative: focus a card, Alt+Left/Right moves it between lanes, Alt+Up/Down reorders, Enter opens, Delete removes; live-region announcements (`role="status"`, `aria-live="polite"`) |
| Dialogs | The native `<dialog>` element (focus handling, Escape); tabs follow the ARIA tab pattern with arrow-key navigation ([ADR-029](../../adr/029-dialog-system.md)) |
| Execution pages | The executions list and the flow page have live regions for updates; the list is a table; the step list is plain markup |
| Graph editor | A focused node can be moved with the arrow keys (Shift for larger steps), opened with Enter and deleted with Delete; a selected connection is deleted with Delete; the inspector is ordinary form controls |
| Motion | `prefers-reduced-motion` is respected; dark and light themes |
| Text | Output, reasons and data are rendered as text, never as markup |

**What does not work, and is a known limitation**

- **Creating a connection between nodes in the graph editor is a pointer gesture** (drag from a port to a port). The select that
  once offered a keyboard path was removed ([ADR-014](../../adr/014-building-blocks-and-extension-points.md)). A keyboard or
  screen-reader user cannot build or rewire a pipeline.
- The graph canvas has no text alternative of the whole graph; the flow view of an execution is a drawing with a step list
  next to it, not a full accessible description of the path.
- There is no documented audit with assistive technology; the statements above come from the code, not from tests with a screen reader.

The limitation is also a risk entry ([chapter 11](../11-risks-and-technical-debt.md)). A later change designs keyboard connection
creation (for example choose a source node, then a target from a list) and brings the editor to the same level as the board.
