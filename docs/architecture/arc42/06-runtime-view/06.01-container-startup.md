## 6.1 Container startup

```
┌────────┐   docker compose   ┌──────────────┐   entrypoint   ┌──────────┐
│  User  │ ───────────────►   │ OpenArtifact │ ────────────►  │  SQLite  │
│        │                    │   Container  │                │  (WAL)   │
│        │ ◄────────────────  │              │ ◄─────────────│          │
│  curl  │   GET /health      │              │    data_dir    │          │
│ browser│   GET /           │              │                │          │
└────────┘                    └──────────────┘                └──────────┘

Startup:
  1. docker-entrypoint.sh runs:
     a. Set env defaults (OPENARTIFACT_*)
     b. Run: alembic upgrade head
        → Create database directory if needed
        → Apply all migrations up to head (0001–0012)
        → Log: "Migrations completed successfully."
        → If migration fails: exit 1 (container stops)
     c. exec uvicorn --factory
        → Settings loaded from env vars
        → _build_engine: connect SQLite, enable WAL
        → Verify: SELECT 1
        → Log: "Database connected at /data/openartifact.db"
        → FastAPI lifespan _startup: log identity
        → Register routes (api + web)
        → Bind to 0.0.0.0:2909

Shutdown:
  1. SIGTERM received (docker stop, compose down)
  2. FastAPI lifespan _shutdown: dispose_engine()
  3. uvicorn exits cleanly
  4. Container stops
```
