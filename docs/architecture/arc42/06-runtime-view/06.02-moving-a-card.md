## 6.2 Moving a card (optimistic update with live sync)

```
Browser A                        Server                           Browser B
 drop card ─ upsert (optimistic)
 PATCH /api/tasks/{id} ────────► validate, place (fractional position),
                                 commit ─► EventBus.publish(task.moved)
 ◄──── 200 task ─────────────── ───────────────────────────────────► SSE task.moved ─► upsert
 upsert(server state)
 on error: upsert(previous) + message
```

If a lane has to be renumbered (gap below 1e-6) the server publishes `board.resync` and every
client reloads the list. After an SSE reconnect each client reloads as well, because missed events
are not replayed.
