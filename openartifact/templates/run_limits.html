Limits of one execution. An execution keeps the limits it started with: a change applies to the executions that start afterwards.

Every action and every node of its definition is a step. A pipeline that loops (an On Error back into its own action, for example) fails when it reaches this number.

When the time is up, the node that is running is stopped and the execution fails with the reason. The nodes have time limits of their own (Code, HTTP, Agent) on top of this.
